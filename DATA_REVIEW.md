# Four lines are not enough

The first small-model poetry generator returned 128/128 answers with four nonempty lines. It cost approximately $0.056 of timed requested compute. That looks excellent if the only metric is line count. Reading the answers tells a different story.

Actual generated answer to **“Co znaczy błąd 404?”**:

> Gdy strona się zniknie, jak cień w mroku,  
> To błąd czterdziesty cztery, smutku potok.  
> Serwer milczy cicho, bez żadnej odpowiedzi,  
> Że tamten adres już nie ma już odpowiedzi.

Problems: broken grammar, 404 becomes “forty-four,” a 404 response is described as server silence, and repeating *odpowiedzi* substitutes for a rhyme. The four-line filter catches none of these. Another example answers a Polish autocomplete question in English.

The replacement authored training answer is:

> Serwer ci odrzekł: pod tym adresem  
> Nie mam zasobu, choć bywał tu czasem.  
> Sprawdź ścieżkę, nim nowe postawisz pytanie,  
> Może literówka zatrzymała żądanie.

This is short workshop verse, not a claim of literary mastery. It preserves the key fact: the server responded, but could not find the resource. Review the rest with the same care. Some rhymes are imperfect; participants can improve the dataset rather than simply adding more epochs.

The comic-persona alternative on the same topic:

> 404: serwer odebrał, ale pod tym adresem nikt nie mieszka. Sprawdź literówki i ścieżkę, zanim zaczniesz przesłuchiwać router.

Exercise: label five examples for **answers the question**, **correct content**, **natural language**, and **style**. Disagree about the judgments, then decide what you would accept into training. Keep evaluation questions separate. Using a four-line reward for poetry would invite reward hacking; it is not an adequate RLVR verifier for literary quality.
