# Workshop guides

Follow the [three-hour agenda](workshop.md), then use these guides during each exercise. All shell commands assume the repository root as the working directory.

1. [Data, tokenization and pretraining](pretraining.md): Polish Wikipedia markup, 8k BPE and training from random weights.
2. [Prawko: SFT, RLVR and evaluation](prawko.md): the main shared post-training task.
3. [Poetry SFT](poetry.md): optional *Pan Tadeusz* question → verse exercise.
4. [Other RLVR tasks](rlvr.md): six-word stories, arithmetic and mazes.

[Model choices](models.md) records the tested shortlist. [Background notes](notes/) preserve earlier designs, source investigations and extensions; the current three-hour agenda supersedes older four-hour plans.
